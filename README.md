# دعوت نامه محمد و محبوبه

این repository نسخه خصوصی صفحه و تاریخچه تغییرها را نگه می دارد. سایت منتشرشده از لینک عمومی دیده می شود؛ اطلاعات داخل خود صفحه برای هر بازدیدکننده قابل مشاهده است.

## ویرایش و انتشار

1. فایل اصلی صفحه `index.html` است.
2. بعد از هر تغییر، آن را در branch `main` commit و push کنید.
3. GitHub Actions پس از هر push به `main` سایت را دوباره منتشر می کند. لینک سایت همیشه آخرین نسخه منتشرشده را نشان می دهد.
4. فایل های عکس آینده را در پوشه `assets` قرار دهید و مسیرشان را در `index.html` به روز کنید.

فقط `index.html` و پوشه `assets` به سایت کپی می شوند؛ `README.md` و فایل های workflow در لینک عمومی سایت نمایش داده نمی شوند.

## فرم RSVP

فرم فعلی فقط پیام نمایشی نشان می دهد و پاسخ ها را ذخیره یا ارسال نمی کند. برای دریافت واقعی پاسخ ها باید یک سرویس فرم یا backend به آن وصل شود.
